## Decisión fundamentada

Mantener abierto el Sprint6. US20 tiene evidencia técnica local nueva, pero faltan la matriz nativa Chrome/Edge, fluidez visual comparativa/prolongada, actualidad NVD, aceptación representativa y online autorizado. Las capacidades de datos/cálculos no sustituyen RNF4 visual. El código contempla las historias y existen regresiones API; eso no demuestra todos los criterios originales. No se declara candidata de cierre técnico total ni versión estable. Las reglas de relojes aceptadas se conservan y no son un pendiente funcional.

No hay evidencia Git para atribuir trabajo individual. Datos/secretos/perfiles de prueba no se distribuyen. Cierre solo después de evidencias faltantes y aceptación real; las herramientas bloqueadas se documentan sin simular resultados.
