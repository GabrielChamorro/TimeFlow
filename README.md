# TimeFlow

Proyecto APT desarrollado para organizar jornadas de trabajo y tareas desde una aplicación web.

## Funciones principales

- Inicio de sesión para administrador y trabajadores.
- Registro de Check In y Check Out.
- Creación, seguimiento y administración de tareas.
- Monitoreo de tareas en el mapa.
- Control de permisos y almacenamiento de datos en MySQL.

## Tecnologías

- Frontend: React y Vite.
- Backend: Java 21 y Spring Boot 4.1.2.
- Base de datos: MySQL 8.4.
- Pruebas: JUnit, Postman y OWASP Dependency-Check.

## Proyecto y documentación

La versión de referencia es TimeFlow V0.5.0. El equipo organizó el desarrollo con Scrum y documentó los avances por sprint. Los informes, las pruebas y las capturas se guardan en las carpetas de documentación y evidencias del repositorio.

## Instalación

En Windows, ejecutar `INSTALAR_DEPENDENCIAS_TIMEFLOW.bat` desde la carpeta principal. La configuración local de MySQL y las claves de seguridad se almacenan fuera del repositorio mediante los archivos y variables que crea el instalador.

No se deben subir contraseñas, tokens, archivos de configuración privados ni copias de bases de datos con información real.
